# Assignment_02

## Files

- `rental.py` - Contains the Vehicle, Renter, ElectricCar, and Motorbike classes.
- `main.py` - Demonstrates the rental system, validation, inheritance, and polymorphism.
- `README.md` - Instructions and AI-use note.

## How to Run

Open a terminal in the `Assignment_02` folder and run:

```bash
python main.py
```

To run the pytest tests, use:

```bash
python -m pytest
```
